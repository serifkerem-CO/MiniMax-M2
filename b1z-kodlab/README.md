# B1Z KODLAB 🚀

> **"Kodla, Kodlat, B1Z Ol"** — Tüm Kodlayan ve Kodlama Öğretenlere Platform

## 🌟 Vizyon

B1Z KODLAB, **MiniMax-M2** AI modelini kullanarak kodlama öğrenen ve öğretenlerin buluşma noktası. Gerçek zamanlı AI mentorluğu, topluluk işbirliği ve "11 Akıl Harmanları" sistemiyle yeni nesil kodlama eğitimi platformu.

## 🎯 3 Ana Modül

### 1. **KODLA**
Canlı kod editörü ile hands-on kodlama:
- Python, JavaScript, Rust, Go desteği
- Gerçek zamanlı AI feedback (MiniMax-M2)
- "11 Akıl Harmanları" analizi
- Challenge modu ve günlük yarışmalar

### 2. **KODLAT**
AI öğretmeni ile adım adım eğitim:
- "Bana X'i Öğret" butonu
- Kişiselleştirilmiş öğrenme yolları
- Maya Modu: Görsel + İşitsel + Etkileşimli

### 3. **B1Z**
Topluluk ve işbirliği:
- Ortak proje alanı
- Canlı kodlama seansları
- 1111 Soru-Cevap sistemi
- Şifalı Cevaplar™

## 🏗️ Teknik Stack

**Backend:**
- FastAPI (Python)
- MiniMax-M2 API entegrasyonu
- Firebase / PostgreSQL
- WebSocket (canlı yayın)

**Frontend:**
- React.js + TypeScript
- TailwindCSS (1111 teması)
- Monaco Editor (VS Code editörü)
- WebRTC (canlı işbirliği)

```bash
npm run dev
```
